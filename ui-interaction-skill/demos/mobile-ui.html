Tab 滑动切换 Swipeable Tabs

内容区是一条 snap 轨道（惯性免费），指示器 ink 由 scrollLeft 实时驱动，点击 Tab 平滑滚动到页。选中态等 scrollend 才切换。

推荐流

内容跟手 + 惯性全由原生滚动提供，JS 只做一件事：把 scrollLeft 换算成指示器位移。

关注流

注意指示器是 transform: translateX 驱动，不是 left 动画 —— 零重排。

视频流

松手吸附后 scrollend 触发高亮切换；滑动过程中高亮不乱跳。

左右滑内容 · 或点 Tab · 观察指示器跟手程度
