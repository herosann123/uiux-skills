# UI 交互 Skill · 高级模式选择与实现

> 24 种核心交互模式 + 模块级映射表 + 决策树。
> 配套 demo：`./10-ui-interactions.html`（①-⑩）+ `./advanced-ui-v2.html`（⑪-⑰）+ `./advanced-ui-v3.html`（⑱-㉔）
> 配套技术手册：`./PATTERNS.md`（每种模式的完整代码模板 + 调参指南）

## 0. 如何使用本 Skill

**被调用时**，按以下顺序响应：

1. **识别模块** —— 用户在为哪个 UI 模块设计交互？
2. **查表** —— 跳到 §4「模块 → 模式映射表」，找到该模块的推荐模式
3. **查代码** —— 如需实现细节，跳到 `PATTERNS.md` 找对应模式的代码模板
4. **避坑** —— 检查 §7 反模式 + §8 性能预算
5. **减法前置** —— 用户要「再加一个动效」时，先过 §11.2 减法决策表，再决定是否新增
6. **可访问性** —— 每个动效必须有 `prefers-reduced-motion` fallback
7. **输出与验收** —— 模式推荐按 §11.1 四层分级输出；被要求评审/验收时遵守 §11.3 盲评包与 §11.4 四态结论

**用户可能的输入**：
- `/ui-interaction-skill hero` → 给 Hero 推荐方案
- `/ui-interaction-skill 按钮 磁吸` → 为按钮找磁吸实现
- `/ui-interaction-skill --html` → 给所有 24 个 demo 的 HTML
- `/ui-interaction-skill ㉑` → 解释模式 ㉑ 并给完整代码

## 1. 触发条件

**应该使用本 skill 的场景：**

- 设计新页面的动效时
- 现有页面"感觉太通用"，需要升级到 premium 质感
- 实现具体模块（Hero / 卡片 / 按钮 / Loading / Modal 等）的交互
- 客户/产品要求"高级感"、"App Store 风格"、"有质感"

**不应该使用的场景：**

- 数据密集型后台工具（动效反而干扰效率）
- 低端机 / 嵌入式 / 强性能约束
- 用户明确要"极简"、"静态"

## 2. 核心决策框架：输入 × 策略 二维矩阵

所有交互都可以从「**输入是什么**」和「**变换什么属性**」两个维度分类：

```
              Position   Scale    Filter   Path    Physics
              位移       缩放     视觉     路径    物理
              ──────────────────────────────────────────────
Scroll   滚动     ① 视差     ② 触发动画
Gesture  手势     ③ 堆叠 ④ 磁吸                      ⑦ 弹性
Time     时间轴   ⑤ 文字揭示                    ⑥ SVG ⑧ 数字
Pointer  光标     ⑨ 3D 倾斜                  ⑩ 玻璃
```

**口诀**：先想「输入从哪儿来」，再想「要变换什么」。两者交叉就是答案。

  │
  ├─ 模块：数据/数字展示（统计/计数器/计数器）

  │    └─ 推荐：⑥ SVG 路径绘制
  │

  │    └─ 推荐：⑩ 玻璃拟态（背景） + ⑤ 文字揭示（内容）
  │
  ├─ 模块：设置开关 / 主题切换 / 状态卡
  │    └─ 推荐：⑩ 玻璃拟态
  │
  ├─ 模块：Loading / 加载占位
  │    └─ 推荐：⑥ SVG 路径（品牌元素） 或 ⑦ 弹性（圆形指示器）
  │
  ├─ 模块：Onboarding / 引导页
  │    └─ 推荐：⑤ 文字揭示（顺序讲故事） + ② 滚动触发
  │
  ├─ 模块：详情/特性展示卡（hover 才有戏）
  │    └─ 推荐：⑨ 3D 倾斜 + 径向高光
  │
  └─ 模块：内容长文阅读页

## 4. ★ 模块 → 模式 映射表（核心）

> 这是 agent 在接到任务后**直接 lookup 的关键表**。
> 查表结果按 **§11.1 四层分级**输出（必须满足 / 推荐方案 / 可选实验 / 禁止或避免），不输出平铺清单。

### 3.1 通用页面元素

| UI 模块 | 推荐模式 | 关键参数 | 备选 | 注意事项 |
|---------|---------|---------|------|---------|
| **Hero 主视觉** | ① 视差 + ⑤ 文字揭示 | 速度 0.1~0.4；stagger 40ms | ⑨ 3D 倾斜（特性卡） | 视差不超过 3 层；首屏文字 1s 内完成 |
| **Hero 高级背景** | ⑪ 极光 + ⑫ 粒子网络 | blob blur 80px；60~100 节点 | ① 视差（图片） | 不要和视差叠加；移动端降级为纯色 |
| **导航栏 Logo** | ⑥ SVG 路径 | duration 1.5~2.5s | ⑤ 文字揭示（文字 logo） | 路径总长 ≤ 1000 为佳 |
| **主 CTA 按钮** | ④ 磁吸 | 系数 0.2~0.35 | ⑦ 弹性（按下回弹） | 移动端**禁用磁吸**，用普通 hover |
| **点击反馈按钮** | ⑬ 水波纹涟漪 | duration 500~700ms | ⑦ 弹性 | 必须从点击位置发出，不能从中心 |
| **次要操作按钮** | 无 / 普通 hover | — | — | 不要每个按钮都加动效 |
| **数字徽章 / 角标** | ⑧ 数字翻牌（变化时） | ease: expo.out | ⑤ 揭示 | 不要每帧都动画 |
| **Loading 占位** | ⑥ SVG 路径（品牌） / ⑦ 弹性（小球） | 600ms≤ duration≤2s | 简单旋转 | loading < 800ms 直接消失，别用 |
| **空状态插画** | ⑥ SVG 路径 | 顺序绘制 0.5~1.5s | ⑦ 弹性（循环） | 首次出现用单次，不要循环 |

### 3.2 内容类模块

| UI 模块 | 推荐模式 | 关键参数 | 备选 | 注意事项 |
|---------|---------|---------|------|---------|
| **特性卡片网格** | ⑨ 3D 倾斜（hover） | rotate ±8~12°；强度 0.3 | ④ 磁吸（整卡） | 移动端降级为普通 hover |
| **卡片 → 详情页** | ⑮ FLIP 共享元素 | duration 350~500ms | ⑯ View Transitions | 共享元素必须有稳定 key/id；列表 → 全屏 |
| **可滑动 Feed 卡** | ③ 卡片堆叠 | 阈值 80~120px | 普通 swipe-to-dismiss | 屏幕只允许 1 张可拖 |
| **数字展示 / 统计** | ⑧ 数字翻牌 | ease: expo.out | ① 视差（数字墙） | 单次进入动画，不要循环 |
| **图文混合段落** | ② 滚动触发（淡入） | 阈值 0.2；y: 30 | 不动 | 不要用视差，会影响阅读 |
| **轮播 / Banner** | ⑨ 3D 倾斜（active 项） | rotate ±6° | ⑤ 文字揭示 | 一次只强调一张 |
| **长列表** | 无（保持冷静） | — | — | 列表项**不要**加 hover 动效 |

### 3.3 导航与状态

| UI 模块 | 推荐模式 | 关键参数 | 备选 | 注意事项 |
|---------|---------|---------|------|---------|
| **设置开关 / Toggle** | ⑩ 玻璃拟态 | blur 16~24px | 普通 toggle | 模糊过重会掉帧，blur ≤ 24px |
| **主题切换 / SPA 路由** | ⑯ View Transitions | duration 300~500ms | 简单 fade | 必须 Chrome 111+/Safari 18+；旧浏览器降级 |
| **Modal 弹窗** | ⑩ 玻璃拟态 + ⑤ 文字揭示 | blur 20px | fade + scale | 移动端 blur 降到 8~12px |
| **Tab 指示器** | ⑦ 弹性 | k=0.1, d=0.7 | 简单 slide | **不要用 linear** |
| **下拉刷新** | ⑦ 弹性（跟手 + 回弹） | k=0.05, d=0.6 | 简单旋转 | 移动端专用 |
| **Toast / Snackbar** | ⑤ 文字揭示（进入） | duration 0.4s | 普通 fade | 不要持续抖动 |
| **状态变化（on/off）** | ⑩ 玻璃拟态 + ⑦ 弹性 | 200~400ms | 颜色变化 | 颜色 + 形状 + 文字三重提示 |

### 3.4 沉浸式叙事

| UI 模块 | 推荐模式 | 关键参数 | 备选 | 注意事项 |
|---------|---------|---------|------|---------|
| **作品集 / Showreel** | ① 视差 + ⑨ 3D 倾斜 | 慢节奏 0.2~0.3 | ② 滚动触发 | 整页动效要克制 |
| **产品详情页** | ① 视差（背景） + ⑤ 揭示（卖点） | 慢节奏 | ⑨ 3D 倾斜 | 关键信息别藏在动效后 |
| **Onboarding 引导** | ⑤ 文字揭示（顺序） | stagger 60ms | ② 滚动触发 | 每屏 1 个核心动画 |
| **垂直滚动叙事** | ⑭ 粘性滚动堆叠 | 面板 80~120vh | ② 滚动触发 | 移动端改成普通竖排，避免 sticky 卡顿 |
| **品牌故事页** | ⑥ SVG 路径（logo） + ⑤ 揭示 | 总时长 3~5s | ① 视差 | 视频感，不要过密 |
| **营销活动页** | ① 视差 + ④ 磁吸 + ⑤ 揭示 | 节奏快 0.3~0.5 | ⑨ 3D 倾斜 | 必须有"下一步"明确 CTA |
| **AI 产品落地页** | ⑫ 粒子 + ⑰ 流式打字机 | 节点 60~80；字符 20~40ms | ⑪ 极光 + ⑮ FLIP | 流式打字机**必须**配光标，否则不像 AI |
| **AI 对话气泡** | ⑰ 流式打字机 | 字符 20~40ms | ⑥ SVG 路径（图标） | 中途换行要保留换行符；标点延迟 ×3 |
| **高端品牌落地页** | ⑱ 自定义光标 + ⑳ 噪点 + ㉑ Glitch（标题） | 内点立即，外圈 0.18 阻尼；噪点 opacity 0.25；偏移 2~4px | ⑲ 水平叙事 | 移动端禁用光标；噪点要 can-toggle 关闭 |
| **Apple 风产品页** | ⑲ 水平滚动叙事 + ㉒ 滚动驱动数字 | 横向 4~6 屏；数字 0~N | ① 视差 + ⑤ 揭示 | 必须 ScrollTrigger pin + scrub；移动端改竖排 |
| **故障感 / Tech 风** | ㉑ RGB 分离 + ⑳ 噪点 | 关键帧 90%~98% 抖动；噪点 mix-blend-mode: overlay | ⑫ 粒子 | 不要让 Glitch 全程抖，会疲劳 |
| **数据叙事长页** | ㉒ 滚动驱动数字 + ⑧ 翻牌 | progress 0~1 → 0~N；lerp 0.15 | ② 滚动触发 | tabular-nums 防止数字跳动 |
| **Power User 工具** | ㉓ Cmd+K 命令栏 + ⑬ 涟漪（按钮） | 快捷键 Cmd/Ctrl+K；高亮 `<mark>` | ⑫ 粒子（背景） | 必须支持 ↑↓ Enter Esc；空状态文案 |

### 3.5 移动端 / 小程序特殊考虑

| 模块 | 推荐模式 | 关键参数 | 替代 | 注意事项 |
|------|---------|---------|------|---------|
| **小程序启动屏** | ⑥ SVG 路径（logo） | 1.5~2s | 简单淡入 | 动画结束才让用户操作 |
| **小程序下拉刷新** | ⑦ 弹性 | 自定义曲线 | 旋转 spinner | 用 wx.createAnimation |
| **小程序弹窗** | ⑩ 玻璃拟态 + ① 视差（背景层） | blur 8~16px | slide-up | iOS 性能 ≥ iOS 15 才能 blur |
| **App 原生按钮** | ⑦ 弹性（按下） | UIImpactFeedback | 中 | 配合触感反馈 |
| **触底反弹** | ⑦ 弹性 | k=0.06, d=0.65 | overscroll-behavior: contain | 注意 iOS rubber band 冲突 |

## 5. 模式速查表（详见 PATTERNS.md）

| # | 模式 | 一句话原理 | 关键参数 | 复杂度 |

| ② | **滚动触发** | 元素进入视口进度 → 0→1 动画进度 | scrub, threshold 0.2 | ⭐⭐ |

| ⑤ | **文字揭示** | 字符串拆词 → stagger 入场 | stagger 30~60ms, expo.out | ⭐⭐ |
| ⑥ | **SVG 路径** | stroke-dashoffset 100% → 0% | duration 1.5~2.5s | ⭐⭐ |
| ⑦ | **弹性回弹** | F = -kx - cv 每帧更新 | k=0.08, d=0.78 | ⭐⭐⭐ |
| ⑧ | **数字翻牌** | 0~9 垂直堆叠 + translateY(-n*10%) | ease: expo.out | ⭐⭐ |
| ⑨ | **3D 倾斜** | perspective + rotateX/Y 跟光标 | ±10~14° | ⭐⭐ |
| ⑩ | **玻璃拟态** | backdrop-filter: blur() + 半透明 | blur 16~24px | ⭐ |
| ⑪ | **极光渐变** | 多色大圆 + mix-blend-mode: screen + 慢动画 | blur 60~120px, 8~15s 循环 | ⭐ |
| ⑫ | **粒子网络** | Canvas 粒子 + 鼠标排斥 + 临近连线 | 30~100 节点，60fps | ⭐⭐⭐ |
| ⑬ | **水波纹涟漪** | click 位置 → radial ripple span + transform scale | 400~700ms | ⭐ |
| ⑭ | **粘性滚动堆叠** | position:sticky 容器 + 内部面板 scroll-触发动画 | 面板 80~120vh | ⭐⭐ |
| ⑮ | **FLIP 共享元素** | First-Last-Invert-Play 列表→详情平滑过渡 | duration 350~500ms | ⭐⭐⭐ |
| ⑯ | **View Transitions** | document.startViewTransition() 浏览器原生过渡 | duration 300~500ms | ⭐⭐ |
| ⑰ | **AI 流式打字机** | 字符 setState + 可变 delay（标点慢）+ 流式光标 | 字符 15~40ms，标点 ×3 | ⭐⭐ |
| ⑱ | **自定义光标** | 双层光标（点+环）+ 阻尼惯性 + hover 放大 | 内点立即，外圈 lerp 0.18 | ⭐⭐ |
| ⑲ | **水平滚动叙事** | 垂直 scrollY → 水平 translateX（pin + scrub） | scrub 1，4~6 屏 | ⭐⭐⭐ |
| ⑳ | **噪点纹理** | Canvas 随机像素 + steps() 抖动 + mix-blend-mode | 0.5x 分辨率，opacity 0.25 | ⭐ |
| ㉑ | **RGB 分离 Glitch** | 3 层文字（R/G/B）+ mix-blend-mode: screen + 关键帧偏移 | 偏移 2~4px，92~98% 区间 | ⭐ |
| ㉒ | **滚动驱动数字** | ScrollTrigger.progress 0~1 → lerp 数字 0~N | duration 不限，lerp 0.15 | ⭐ |
| ㉓ | **命令栏 Cmd+K** | 全局快捷键唤起 + 模糊匹配 + 键盘导航 + 高亮 | Cmd/Ctrl+K，↑↓ Enter Esc | ⭐⭐⭐ |
| ㉔ | **Blob Morph 液态形变** | SVG `<path>` 的 `d` 属性在同点数 path 间 GSAP morph | elastic.out(1, 0.6) | ⭐⭐ |

## 6. 组合配方（关键）

**一屏最多 2 个主模式 + 1 个次要模式**，否则视觉混乱。

| 配方名 | 组合 | 适用场景 |
|--------|------|---------|
| **Premium Hero** | ① 视差（背景层） + ⑤ 揭示（标题） + ④ 磁吸（CTA） | 落地页首屏 |
| **App Store Card** | ⑨ 3D 倾斜（卡） + ⑧ 数字翻牌（评分） + ⑤ 揭示（标题） | 应用商店 / 推荐位 |
| **Tinder Discover** | ③ 卡片堆叠 + ⑩ 玻璃拟态（操作按钮） + ⑦ 弹性（回弹） | 匹配 / 评估类 |
| **Story Scroll** | ② 滚动触发（元素淡入） + ⑥ SVG 路径（段落标头） + ⑤ 揭示 | 长图文叙事 |
| **Dashboard Premium** | ⑧ 数字翻牌（指标） + ⑩ 玻璃拟态（开关） + ⑦ 弹性（指示器） | 高端仪表盘 |
| **Onboarding Sequence** | ⑤ 揭示（步骤） + ⑥ SVG 路径（图标） + ⑦ 弹性（下一页按钮） | 新用户引导 |
| **Aurora Hero** | ⑪ 极光（背景） + ⑤ 揭示（标题） + ⑬ 涟漪（CTA） | 高端品牌 / SaaS 落地页 |
| **AI Product Demo** | ⑫ 粒子（背景） + ⑰ 流式打字机（演示） + ⑯ View Transitions（主题） | AI 产品落地 / ChatGPT 风格 |

## 7. 反模式（必须避免）

### 6.1 错配模块

- ❌ **长文阅读页用视差** → 影响阅读、引起眩晕
- ❌ **移动端小按钮用磁吸** → 触摸坐标不稳定，效果不可靠
- ❌ **文字密集卡片用 3D 倾斜** → 抖动影响可读性
- ❌ **关键 CTA 用文字揭示** → 用户找不到入口，转化率下降
- ❌ **列表项加 hover 动效** → 鼠标划过整列抖动，烦躁
- ❌ **用 spring 做全局导航过渡** → 太慢，体感像卡顿
- ❌ **玻璃拟态用在纯白背景** → 看不见，blur 没意义
- ❌ **SVG 路径动画在 final state 不复位** → 动画结束后虚线错位
- ❌ **极光渐变和粒子网络同时挂在一屏** → GPU 占用爆炸，移动端必卡
- ❌ **粘性堆叠超过 5 屏** → 滚动疲劳，掉帧，移动端尤其明显
- ❌ **AI 打字机不用 setState 而是 innerHTML 整段写入** → 失去"流式"灵魂
- ❌ **水波纹从按钮中心发出** → 廉价感，违反用户预期
- ❌ **FLIP 共享元素不提供稳定 key/id** → 浏览器无法定位，动画失败
- ❌ **自定义光标没在移动端禁用** → 触摸设备光标定位错乱，体验崩
- ❌ **水平滚动叙事的滚轮不 pin 容器** → 内容还没滚完就被甩走
- ❌ **噪点纹理每帧全屏重绘** → 帧率爆炸，必须用 0.5x 分辨率 canvas
- ❌ **Glitch 全程持续抖动** → 用户视觉疲劳，3 秒后只剩厌恶
- ❌ **Cmd+K 没有 Esc 关闭** → 用户被困在面板里
- ❌ **Blob Morph 的两个 path 点数不同** → GSAP 无法插值，形态直接跳变
- ❌ **滚动驱动数字忘开 tabular-nums** → 数字宽度变化引起布局抖动
- ❌ **JS 动态创建的元素挂渐入类(如 .rv)** → 滚动观察器在它诞生前就已收集完毕,永远没人观察它,元素**永久隐形**;渐入必须挂在静态父容器上,子项跟随容器状态入场

### 6.2 错配缓动

- ❌ **`linear`** → 机械感，绝不用在主交互
- ❌ **用 `cubic-bezier` 模拟弹性** → 永远达不到真正的 elastic 那种过冲感
- ❌ **`ease-in`**（开头慢）于入场动画 → 用户等待感变长
- ❌ **持续时间 > 1.5s 的入场动画** → 用户失去焦点
- ❌ **持续时间 < 150ms 的反馈动画** → 看不见

### 6.3 错配叠加

- ❌ **同一屏 > 4 个动效源** → 视觉混乱
- ❌ **滚动驱动 + 指针驱动同时作用同一元素** → 互相干扰
- ❌ **glassmorphism + parallax 同一层** → blur 重计算，性能崩溃

## 8. 性能与无障碍预算

### 7.1 性能预算

| 设备等级 | 同时运行动效 | 持续时长上限 | 避免 |
|---------|------------|------------|------|
| **高端桌面** | ≤ 4 个 | 无限制 | — |
| **中端手机** | ≤ 2 个 | ≤ 600ms | blur > 20px、3D 倾斜 |
| **低端机 / 微信小程序** | ≤ 1 个 | ≤ 400ms | SVG 复杂路径、blur > 12px |
| **iOS Safari** | ≤ 3 个 | ≤ 800ms | backdrop-filter 过深 |

**性能铁律**：
- 只动画 `transform` 和 `opacity`（GPU 加速）
- 不要动画 `width/height/top/left`（layout 重排）
- `filter: blur()` 也要慎用，会重绘
- 长列表用 `will-change: transform` 但要及时移除

### 7.2 无障碍（必须遵守）

```javascript
// 必须：监听 prefers-reduced-motion
const motionQuery = window.matchMedia('(prefers-reduced-motion: reduce)');
if (motionQuery.matches) {
  // 跳过所有动效，直接显示 final state
  return;
}
```

| 模式 | 必须的 fallback |
|------|---------------|
| 视差 | 静态背景层 |
| 滚动触发 | 元素直接可见 |
| 卡片堆叠 | 普通 swipe 列表 |
| 文字揭示 | 文字直接显示 |
| SVG 路径 | 直接显示完整路径 |
| 3D 倾斜 | 普通静态卡 |
| 弹性 | 即时跳到 final state |
| 玻璃拟态 | 不透明实色背景 |
| 数字翻牌 | 直接显示最终数字 |
| 磁吸 | 静态按钮 |
| ⑪ 极光渐变 | 纯色静态背景 |
| ⑫ 粒子网络 | 静态背景图 / 关掉 canvas |
| ⑬ 水波纹涟漪 | 普通按钮颜色反馈 |
| ⑭ 粘性滚动堆叠 | 普通竖排布局，去掉 sticky |
| ⑮ FLIP 共享元素 | 普通 fade-in（不要 transform） |
| ⑯ View Transitions | 即时切换，无过渡 |
| ⑰ AI 流式打字机 | 一次性显示完整文字 |
| ⑱ 自定义光标 | 显示原生光标 |
| ⑲ 水平滚动叙事 | 普通竖排布局 |
| ⑳ 噪点纹理 | 纯色静态背景 |
| ㉑ RGB 分离 | 单一颜色文字，无分层 |
| ㉒ 滚动驱动数字 | 显示最终数字，无动画 |
| ㉓ 命令栏 | 仅在导航菜单展示所有功能 |
| ㉔ Blob Morph | 静态 SVG 形状 |

**三冗余原则**：关键状态变化必须**颜色 + 形状 + 文本**三重提示，不只靠动效。

## 11. 输出、评审与验收协议

> v2.1 新增。协议方法借鉴 `uiux-design-suite` 并按本 skill 的模式推荐/评审场景适配；
> 对抗性测试场景见 `evals/scenarios.md`。

### 11.1 输出分级契约（四层）

任何「该用什么模式」的回答按以下四层组织，不输出无主次的平铺清单：

| 层级 | 含义 | 例子 |
|------|------|------|
| **必须满足** | 违反即返工的硬约束 + 验收方式 | 移动端禁用磁吸；必须有 reduced-motion fallback |
| **推荐方案** | 一条可行路线；执行者有证据时可换等效方案 | 主 CTA：桌面 ④ 磁吸 / 移动 ⑦ 弹性按压 |
| **可选实验** | 预算允许才试，失败可撤销 | 第二屏尝试 ⑲ 水平叙事 |
| **禁止或避免** | 保护任务与性能的边界；不给无依据的永久审美禁令 | 长文页不加视差；同屏动效源 ≤ 4 |

### 11.2 减法决策（先删后加）

用户想「再加一个动效」时，**先过减法表，再决定是否新增**：

| 检查项 | 问题 | 处理 |
|--------|------|------|
| 信息价值 | 该元素在信息 / 操作 / 反馈 / 识别上有作用吗？ | 无作用 → 删，不降级保留 |
| 重复说明 | 同一信息是否已被视觉表达？ | 文字 + 动效 + 颜色三重冗余 → 留其一 |
| 任意强调 | 高亮 / 动效指向核心任务，还是随机装饰？ | 随机强调 → 删 |
| 过量效果 | 同屏动效源 > 4 个？ | 删到 ≤ 2 主 + 1 次 |
| 定制组件 | 原生 / 已有组件是否已够用？ | 够用 → 用原生 |

每条删除建议必须回答两个问题：**原有作用是什么、必要信息如何保留**。
不把极简当统一答案——不删关键操作反馈、错误提示、可访问名称、真实业务信息。

### 11.3 评审协议（盲评输入包）

被要求「评价 / 打分我的页面」时：

- **允许输入**：真实截图（标注视口 / 页面状态 / 版本）+ 可选质量参考图 + 一句固定的产品用途说明
- **禁止输入**：源码实现细节、作者设计理由、历轮评价与分数、期望分数
- **无截图 → 不做视觉评价**：只能给代码级 / 规格级意见，不得编造画面或分数
- 评审结论区分「看到了什么」与「推断意图是什么」，低信心判断明确标注
- 同一上下文无法隔离时标注「非独立评审」；换口吻 ≠ 盲评
- 静态截图推不出：点击行为、键盘焦点、性能数值、真实用户成功率 → 移交验收环节

### 11.4 验收四态结论

任何「做好了没有」的验收，逐项给出四态，不用二元通过 / 失败：

| 状态 | 含义 | 触发条件 |
|------|------|---------|
| ✅ 通过 | 亲自验证过证据 | 真实截图 / 行为测试 / 浏览器操作 |
| ❌ 未通过 | 有反证 | 移动端拖拽被 pointercancel 掐断 |
| ⚠️ 未验证 | 没证据，既不能过也不能算失败 | 实现者自称已修复但无新截图 |
| ➖ 不适用 | 本项不在范围，必须说明理由 | 桌面专用模式不测触屏 |

**铁律**：实现者自测只是「待核验声明」；关键项未验证时不得整体放行；高审美分不能抵消未验证项。
