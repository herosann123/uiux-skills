53height:auto 过渡 · 手风琴

grid-template-rows: 0fr → 1fr —— 不测高、不写 max-height: 999px，全浏览器可用

为什么 0fr 能压下去？ ▾

grid item 默认 min-height: auto 会撑住内容，所以子元素必须 min-height: 0 + overflow: hidden —— 这两行是「不生效」时的第一嫌疑。

interpolate-size 和它什么关系？ ▾

Chrome 129+ 可以 :root { interpolate-size: allow-keywords } 让 height: auto 直接参与过渡，代码更直白；grid 法是全兼容默认方案，两者按 @supports 分层即可。

展开期间内容能交互吗？ ▾

可以，但插值期间子内容被 overflow 裁剪，注意别把可点击元素贴边放；表单控件在收起态依然可聚焦，需要 inert 或 visibility 联动时另行处理。

55跨文档 View Transitions（MPA）

@view-transition —— 普通多页站也能有共享元素飞行，不用改成 SPA

/* 两页都加载的公共 CSS */
@view-transition { navigation: auto; }
@media (prefers-reduced-motion: reduce) {
  @view-transition { navigation: none; }
}

/* 列表页与详情页的同一张图同名 → 飞行 */
.hero-img { view-transition-name: hero-img; }

/* 新页：让 hero 先渲染再放行截图，避免拍到空白 */
<link rel="expect" href="#hero-img" blocking="render">

本页无法单文件演示（需要两个同源页面导航）；demo 首页 → 任一 demo 页的跳转在部署后即生效（本站已开启）。SPA 内对应的是 ⑯ 号同文档 startViewTransition()。徽章探测的是同文档 VT 支持。
