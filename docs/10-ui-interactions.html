01
Scroll-driven · 输入 = 滚动距离

视差滚动

不同图层以不同速率反向位移，制造深度错觉。本质是把「滚动距离」乘以一个 速率系数 喂给每层的 translateY。系数差异越大，深度感越强。

demo · scroll inside page
↓ Scroll the page ↓
// 核心：每帧读取 scrollY，按 speed 系数位移
const layers = document.querySelectorAll('.parallax-layer');

window.addEventListener('scroll', () => {
  const y = window.scrollY;
  layers.forEach(layer => {
    const speed = +layer.dataset.speed;
    layer.style.transform = `translateY(${y * speed}px)`;
  });
});

Gesture-driven · 拖拽跟手

卡片堆叠滑动

跟手阶段实时绑定 transform；松手阶段靠 阈值 + 速度 二选一决定「飞出」还是「弹簧回位」。鼠标拖拽即可，松手后新卡片从下层补上。

// 简化版：跟手 + 松手判定
let dx = 0, startX = 0;

card.addEventListener('pointerdown', e => {
  startX = e.clientX;
  card.setPointerCapture(e.pointerId);
});

card.addEventListener('pointermove', e => {
  dx = e.clientX - startX;
  card.style.transform = `translate(${dx}px,0) rotate(${dx*0.1}deg)`;
});

card.addEventListener('pointerup', () => {
  if (Math.abs(dx) > 120) fly(dx > 0 ? 1 : -1);
  else gsap.to(card, { x: 0, rotation: 0, duration: 0.6, ease: 'elastic.out(1,0.5)' });
});
04
Pointer-driven · 光标吸引

磁吸按钮

把光标位置转成相对按钮中心的偏移向量，乘上一个「吸附强度系数」喂给 transform。系数 0.2~0.4 最舒服 —— 完全跟手（=1）会像被拽走，太小又没存在感。

demo · move cursor near button
Move cursor · 移动鼠标 Tap · 轻触按钮试试 
// 核心：鼠标偏移 × 0.3 强度系数
btn.addEventListener('mousemove', e => {
  const r = btn.getBoundingClientRect();
  const cx = r.left + r.width / 2;
  const cy = r.top + r.height / 2;
  const dx = (e.clientX - cx) * 0.3;
  const dy = (e.clientY - cy) * 0.3;
  btn.style.transform = `translate(${dx}px,${dy}px)`;
});

btn.addEventListener('mouseleave', () => {
  btn.style.transform = 'translate(0,0)';
});

Timeline · 时间轴驱动

文字逐字揭示

把字符串拆成 字符 / 词，每个单位装进一个 overflow:hidden 的 mask，内部 span 从下方滑入。stagger 决定节奏 —— 30ms/字紧凑，60ms/字从容。

06
Timeline · 描边动画

SVG 路径绘制

SVG 的 stroke-dasharray 控制虚线长度，stroke-dashoffset 把虚线偏移出去 —— 当长度 = 周长时，偏移从周长动到 0，视觉上就是「画出」。

demo · click redraw
Click to redraw · 点击重绘
// 1. 拿到路径总长
const path = document.querySelector('path');
const length = path.getTotalLength();

// 2. 设置虚线长度 + 初始偏移
path.style.strokeDasharray = length;
path.style.strokeDashoffset = length;

// 3. 动画：偏移归 0 = 画出
gsap.to(path, {
  strokeDashoffset: 0,
  duration: 2,
  ease: 'power2.inOut'
});
07
Physics · 弹簧物理

弹性回弹

放弃 CSS 的 cubic-bezier，用 胡克定律 F = -kx - cv 每帧更新加速度→速度→位置。k 越大越硬，c 越大越快收敛。GSAP 用 elastic.out，Framer Motion 默认就是弹簧。

demo · drag & release
Drag ball · 拖拽小球
k (stiffness) = 0.08 d (damping) = 0.78 
// 弹簧公式：每帧更新 v, x
let x = 0, v = 0, target = 0;
const k = 0.08, d = 0.78;   // stiffness, damping

function tick() {
  const a = -k * (x - target) - d * v;
  v += a;
  x += v;
  ball.style.transform = `translate(${x}px,0)`;
  requestAnimationFrame(tick);
}
tick();

Timeline · 数字翻牌

数字翻牌计数

每位数字 0~9 垂直堆叠在一个高度 = 1.2em 的容器里，显示数字 n 就是 translateY(-n * 10%)。配合 ease.expo 的缓出曲线才有「先快后慢停」的爽感。

demo · click to animate
Total Visitors · 总访客

// 每位数字：垂直堆叠 0-9，translateY 切换
function setDigit(strip, n) {
  gsap.to(strip, {
    yPercent: -n * 10,
    duration: 0.8,
    ease: 'expo.out'
  });
}

// 总动效：obj 累加到目标，tween onUpdate 里逐位 setDigit
gsap.to(obj, {
  value: 12345.67,
  duration: 2.4,
  ease: 'expo.out',
  onUpdate: () => {
    const s = obj.value.toFixed(2).padStart(9, '0');
    [...s].forEach((ch, i) => ch === ',' ? 0 : setDigit(strips[i], +ch));
  }
});

3D · 视觉欺骗

3D 倾斜跟随光标

父元素加 perspective 建立 3D 空间；子元素 rotateX/Y 与「指针相对中心」的偏移成正比。配合径向高光贴在指针位置 = 真实感拉满。

// 核心：perspective + rotateX/Y 跟随光标
card.addEventListener('mousemove', e => {
  const r = card.getBoundingClientRect();
  const cx = r.left + r.width / 2;
  const cy = r.top + r.height / 2;
  const dx = (e.clientX - cx) / r.width;
  const dy = (e.clientY - cy) / r.height;

  card.style.transform = `
    perspective(1200px)
    rotateY(${dx * 12}deg)
    rotateX(${-dy * 12}deg)
    translateZ(0)
  `;
});

Visual · 玻璃拟态

玻璃拟态切换

靠 backdrop-filter: blur() 模糊后面内容 + 半透明白色背景 + 1px 内描边。注意 filter 是状态属性，无法直接动画 —— 切换时只能 toggle class 让 blur 跳变。

demo · toggle states

Zen Mode

减少干扰，只保留最重要的通知。开启后系统将进入低噪音状态。

// 核心 CSS
.glass {
  background: rgba(255, 255, 255, 0.15);
  backdrop-filter: blur(20px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.3);
}

// ⚠️ backdrop-filter 是状态属性，不能 transition。
// 切换时只能 toggle class，blur 直接跳变。
