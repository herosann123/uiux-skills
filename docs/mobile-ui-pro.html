㉝

橡皮筋阻尼 Rubber-Band

把列表滚到顶，继续向下拉：对数阻尼 c*(1-1/(dx/c+1)) —— 手拖 300px 内容只移 ~130px，越拉越紧；松手带轻微过冲回弹。

阻尼位移 0px

先滚回顶部 → 再往下拉 · 松手看回弹

㉞

捏合缩放 Pinch-to-Zoom

双指捏合：缩放锚定在双指起点；松手 scale<1 弹回、scale>1.8 吸附放大。双击 toggle。没触屏？用 +/− 按钮（这就是无障碍等价物）。

🖼️

㉟

坍缩头图 Collapsing Header

顶上拉：stretch（origin 底边锚定，往上长）；往上滚：头图半速视差 + bar 跟随。全程只动 transform + rAF 节流，不劫持滚动。

Ada 的空间 · 128 篇

滚到顶再下拉 → stretch · 向上滚 → 视差收缩

㊱

长按拖拽排序 Drag-to-Reorder

长按任意行 300ms浮起（scale + 阴影 + 触感）→ 拖动：其他行 transform 让位；每次换位「咔哒」snap 触感；松手才真实结算 DOM。

长按住一行拖到新位置 · 松手落位

㊲

完整下拉刷新 Pull-to-Refresh

滚到顶继续下拉：spinner 跟手旋转（3°/px）→ 超过 80px 文案切换「松开刷新」→ 松手吸附 loading 位 → 打勾 500ms → 自动收起。四态状态机。

下拉刷新

滚到顶 → 下拉 → 松手（不足 80px 会弹回）

㊳

惯性甩动 Momentum Fling

拖动滑块快速甩出后松手：末速延续、摩擦 0.94/帧 衰减滑行、边界 0.4 倍反弹。速度只取最后几个 move —— 慢速放手不甩。

◆
值 50 / 100

按住滑块快速一甩 · 再试试慢慢放手

㊵

液态填充 Liquid Swipe

点击按钮：SVG 贝塞尔「水滴前沿」涌向 100%，前沿永远鼓着、移动越快凸得越多（表面张力感）；文字 mix-blend-mode 随液面自动反白。
