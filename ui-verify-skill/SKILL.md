# UI 实测验收 Skill · 证据先行

> 核心纪律：**每一项结论都必须有可复现的证据**；实现者的自测只是"待核验声明"；
> 关键项未验证时不得整体放行；结论用四态（§6）。

---

## 1. 输入

- 可打开的 URL 或本地文件（本地文件需起 HTTP 服务，`file://` 会破坏部分浏览器 API）
- 目标设备/视口清单（用户给定；未给时用 §2 默认矩阵）
- 本轮改动了什么（用于圈定回归范围；不知道就全量走查）

## 2. 默认视口矩阵

| 档位 | 视口 | 重点检查 |
|------|------|---------|
| 手机 | 390×844（次选 320×568 覆盖小屏） | 溢出、触控目标、单列流、横向滑动类交互 |
| 平板 | 768×1024（横竖各一次） | 断点翻转、栅格退化 |
| 桌面 | 1280×800 | 悬停态、桌面专属模式（如 pin+scrub、自定义光标） |

按项目实际用户设备可替换，但**至少一手机档 + 一桌面档**。

## 3. 测试流程（按序执行）

1. **基础加载**：页面无 JS 报错（挂 error 收集器）、关键资源加载成功、无横向溢出（§P1 脚本）
2. **布局扫描**：元素级溢出扫描定位具体元素（§P1）；字体未加载/图片裂图检查
3. **交互走查**：枚举所有可交互元素（§P2），逐个验证：点击/拖拽/键盘可用、反馈出现、状态复位；触摸类交互用 `pointerType:'touch'` 合成事件验证触摸分支
4. **视口遍历**：同一套检查在每个视口档重复；注意输入方式切换导致的**模式分叉**（如桌面 pin+scrub vs 触摸原生滑动，两条路径都要测）
5. **流程走查**：页面核心任务端到端走一遍（如：填表→提交→成功态→返回修改）；必测**空提交校验**与**回访持久化**
6. **视觉抽查**：每视口至少首屏+核心区截图；截图交给视觉判断时遵循盲评纪律
7. **输出报告**（§6）

## 4. 证据规范

- 每项结论标注：**亲自执行 / 亲自查看 / 实现者转述 / 无证据**
- 行为测试记"动作 → 实际结果"；截图记视口尺寸与页面状态
- 数据检查（如溢出值、transform 值、类名状态）比"看起来正常"更强，优先采数据
- 未采集的证据不得编造文件名或数值

## 5. 已知陷阱（实战踩过,测试时必须考虑）

- **隐藏/后台标签页里 rAF 与 IntersectionObserver 不运行**：测试前确保被测标签页处于前台；否则动画相关检查全部失真
- **浏览器缓存**：改版后用版本参数（`?v=N`）或强制刷新，否则测的是旧页面
- **`scroll-behavior: smooth` 干扰时序**：脚本滚动用 `behavior:'instant'`，断言前留足等待
- **合成事件必须指明 `pointerType`**：派发 `PointerEvent` 不带 type 时触摸分支不会被触发
- **`prefers-reduced-motion` / 真实触屏无法在桌面浏览器模拟**：相关项只能标"未验证"，或用临时注入 matchMedia 桩的测试副本验证**代码路径**（并注明是静态桩测）
- **`100vw` 含滚动条宽度**：全屏元素用 `100%`/`100dvh`，否则桌面出现横向溢出
- **CSSOM 序列化**：`0.0px` 会读成 `0px`，字符串比较断言要做归一化

## 6. 四态结论与报告

每个验收项给出：**✅ 通过 / ❌ 未通过 / ⚠️ 未验证 / ➖ 不适用（须说明理由）**

```markdown
## 验收报告 · <页面> · <日期/环境/视口>
| # | 验收项 | 状态 | 证据 |
|---|--------|------|------|
| 1 | 无横向溢出(390/768/1280) | ✅ | 溢出扫描均为 0 |
| 2 | 触摸拖拽不被 pointercancel 掐断 | ⚠️ | 桌面环境无法真模拟触屏,合成事件已过 |
整体:关键项未验证 → **不予整体放行**
```

**铁律**：关键项 ⚠️ 时不得整体通过；审美分不能抵消未验证项；"不适用"必须解释。

## 7. 无障碍自检（并入每次验收）

- [ ] 文本对比度 ≥ 4.5:1（大字 ≥ 3:1）
- [ ] 键盘可达：核心操作 Tab 可达、Enter/Space 可触发、焦点可见（`:focus-visible`）
- [ ] 可交互元素有可访问名称（图标按钮必须有 `aria-label`）
- [ ] 动效有 `prefers-reduced-motion` 降级（代码审查 + 标注测试局限）
- [ ] 触控目标 ≥ 44×44px
- [ ] 信息不单靠颜色传达（错误态有文字/图标）
- [ ] 弹层：Esc 可关、遮罩可点关、焦点管理

## 8. 边界

- 只验证、不修代码；发现问题输出位置+证据+建议，修复后**重新走一遍相关项**
- 真实设备/真实用户测试不可被桌面模拟替代——模拟不了的项如实标 ⚠️
- 通过 ≠ 无全部缺陷，只代表"本次范围内、所列证据支持下"的结论
