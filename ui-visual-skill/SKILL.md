> 4 套气质色板配方 + 5 套字体配对 + 排版微调参数表 + 廉价感反模式。

## 0. 使用流程

1. **识别气质** —— 产品/内容想传达什么？（§2 决策表选 1 个 archetype，不要混）
2. **取配方** —— 跳 `PATTERNS.md` 复制对应色板令牌 + 字体配对（含 `<link>` 与 fallback 栈）
3. **套排版参数** —— 按 §4 角色表设置 type scale / 字距 / 行高 / 字重
4. **过纪律** —— §5 视觉纪律逐条自检（accent 数量、对比度、透明度阶梯）
5. **避坑** —— §6 廉价感反模式清单
6. **评审** —— 视觉评价遵循 `ui-interaction-skill` §11.3 盲评包（无截图不打分）

## 1. 核心论点

「高级感」不是加东西，是**做对比、做减法**：

- **字体的高级感来自对比**：字重对比（300↔600）＞ 字号对比（1.25 倍率）＞ 字距对比（标签 0.25em+ 宽排 vs 正文 0）。全部用 400/500 中间档 = 平 = 廉价。
- **颜色的高级感来自克制**：带色温的深色代替纯黑、微色偏的浅色代替纯白、同一 ink 的透明度阶梯代替多个灰色、accent 面积 ≤ 10%。
- 一屏之内：**1–2 个字族、5–7 级字号、1 个 accent**。超过就是模板味。

## 2. 气质 → 配方 决策表（核心 lookup）

| 气质关键词 | 色板 archetype | 字体配对 | 适用 |
|-----------|---------------|---------|------|
| 温暖 / 人文 / 邀请 / 手作 / 美食 | **A 编辑暖夜**（奶油底+赤陶+金） | 杂志编辑（Fraunces + Noto Serif SC） | 邀请函、生活方式、作品集 |
| 克制 / 专业 / 建筑 / 画廊 / 极简 | **B 极简画廊**（暖白底+炭黑+朱砂一点） | 极简瑞士（Inter 单字族纪律） | 工作室、摄影、SaaS 官网 |
| 未来 / AI / 开发者 / 夜间 | **C 深空科技**（近黑蓝+薄荷+暗金） | 科技终端（Space Grotesk + Mono） | DevTool、AI 产品、终端风 |
| 传承 / 品味 / 财富 / 稳重 | **D 老钱墨绿**（米白+墨绿+旧金） | 老钱衬线（Playfair + Noto Serif） | 酒店、品牌、财经、高端地产 |
| 活力 / 促销 / 年轻 | 本 skill 不覆盖 | — | 高饱和营销风有自己的规则 |

**规则**：气质含糊时选 B（极简画廊最安全）；两个气质都想选时，问用户砍哪一个——混搭 = 都不像。

## 4. 排版角色参数表（type scale 规格）

| 角色 | 字号 | 字重 | 字距 | 行高 | 备注 |
|------|------|------|------|------|------|
| Display 中文标题 | clamp(48px, 12vw, 120px) | **300**（强调字 600） | 0 ~ 0.02em | 1.05–1.15 | 中文不做斜体（伪斜体=廉价） |
| Display 英文标题 | 同上 | 300–500，可真斜体 | **-0.02 ~ -0.04em** | 0.95–1.1 | 越大越收紧 |
| Eyebrow / 小标签 | 10–11px | 500 | **0.24–0.4em** + uppercase | 1.2 | 宽排是高级感最便宜的开关 |
| 正文 | 14–15px | 400 | 0 | **1.7–1.9** | 长文行高宁大勿小 |
| 数字展示（统计/倒计时） | — | 300 衬线 | 0 | 1.1 | 必须 `font-variant-numeric: tabular-nums` |
| 中英混排正文 | — | 400 | — | 1.8 | 中英文之间留 0.25em 视觉空隙 |

**倍率**：相邻层级字号比 ≈ 1.25（1.333 更戏剧化）；全页层级 ≤ 7。

## 5. 视觉纪律（自检清单）

- [ ] 纯黑 `#000` / 纯白 `#fff` 是否已替换为带色温的近似色？
- [ ] 文字层级是否用**同一 ink 的透明度阶梯**（72% / 52%），而不是另调多个灰？
- [ ] accent 本屏出现 ≤ 2 处（CTA + 一个强调）？
- [ ] 渐变是否只在同色相 / 邻近色相内？（彩虹渐变 = 禁）
- [ ] 深色表面层次是否用明度阶梯（如 `#0b0d10 → #13161c → #1a1e26`）？
- [ ] 正文对比度 ≥ 4.5:1，大字 ≥ 3:1？
- [ ] 阴影是否低饱和（ink 色透明度 8–20%）而非默认黑？
- [ ] 字族数 ≤ 2（+1 个 mono 标签）？

## 6. 廉价感反模式（见到就改）

- ❌ **全 400/500 字重糊中间** → 没有对比就没有层级
- ❌ **uppercase 不加字距** → 挤成一团的标签
- ❌ **中文用 italic** → 伪斜体变形，直接廉价
- ❌ **默认蓝 `#3B82F6` / Tailwind 蓝** → 全网模板色
- ❌ **彩虹渐变按钮 + 大圆角 + 重阴影三件套** → 「AI 生成感」本体
- ❌ **#000 on #fff** → 刺眼且平
- ❌ **灰底上放灰字**（对比度 < 4.5:1）→「高级灰」不等于低对比
- ❌ **一屏 3+ 个 accent 色** → 没有重点就是没有设计
- ❌ **5 种字族混用** → 杂志不是这么编的
- ❌ **长正文居中对齐** → 只有短句（≤2 行）才配居中
- ❌ **描边 + 阴影 + 渐变同时上** → 三选一
- ❌ **图标/emoji 当装饰撒一屏** → 有信息才配出现

## 7. 中文字体工程要点（落地必读）

- **fallback 栈要写全**：`'Noto Serif SC', 'Songti SC', 'Source Han Serif SC', serif`（正文黑体同理：`'PingFang SC', 'HarmonyOS Sans SC', 'MiSans', 'Microsoft YaHei'`）
- **字重只加载 2–3 个**（如 300/400/600）；CJK 字体体积大，多一个字重 = 慢一截
- Google Fonts 的 CJK 会自动按 unicode-range 分片，但 `font-display: swap` 仍要显式声明
- 标题里的 CJK 不会用上拉丁 display 字体（Fraunces 只覆盖拉丁）——**中英混排标题要写两个族**并接受字形不统一，或干脆中文标题全用 CJK 衬线
- **别让思源宋体/思源黑体单独撑大标题**——它们是"全网默认脸"；中文 display 从小薇体/马善政/霞鹜文楷里选（详见 PATTERNS.md §A+）
- 数字优先用拉丁衬线（Fraunces 的数字比 CJK 字体的数字更精致）+ `tabular-nums`

---

## 8. 输出契约

按 `ui-interaction-skill` §11.1 四层分级交付：

- **必须满足**：对比度达标、字族 ≤2、accent ≤2/屏、CJK 不用斜体
- **推荐方案**：气质 archetype 对应的完整令牌 + 字体配对（PATTERNS.md 复制即用）
- **可选实验**：噪点纹理 2–3% / 大号衬线数字 / 真斜体英文点缀
- **禁止或避免**：§6 全部清单
